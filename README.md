# Lancer de rayons en Processing

Projet d'**Informatique de l'image et de la géométrie** (Licence 3 Informatique, Université de limoges), réalisé en binôme avec **Djibrine Moustapha Mahamat**.

Un petit moteur de **ray tracing** écrit étape par étape en Processing (Java) : on envoie un rayon par pixel et on calcule ce qu'il touche.

## Les exercices

| Dossier | Ce qu'on y fait |
|---|---|
| `exercice1` | Dégradé de couleurs pixel par pixel (`image1.png`) |
| `exercice2` | Caméra : un rayon par pixel, couleur = direction du rayon |
| `exercice3` | Intersection rayon / sphère (équation du second degré) |
| `exercice4` | Plusieurs sphères, on garde la plus proche ; grandes sphères = « boîte » colorée |
| `exercice5` | Éclairage : source de lumière, normale, intensité |
| `exercice6` | Ombres portées |

## Lancer

1. Installer [Processing](https://processing.org/download).
2. Ouvrir par exemple `exercices/exercice6/exercice6.pde`.
3. Cliquer sur ▶.

Chaque dossier est indépendant (il contient sa propre copie de `camera.pde`, `rayon.pde`, `sphere.pde`).
